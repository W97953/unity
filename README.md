# Sunny Land - Unity Example

This repository contains a lightweight Unity example project skeleton for the "Sunny Land" 2D game used in the course. It includes core scripts, scene & tilemap setup instructions, and README guidance. You should add your art assets (Sprites / Tilesheets / Animated frames) into Assets/Art/ before opening the project in Unity.

What I added in this commit:
- Core scripts (Assets/Scripts): PlayerController, Collectible, GameManager, CameraFollow
- README and small docs (Assets/Tiles/README.md and Scenes/README.md)
- .gitignore for Unity

Next steps for you:
1. Open this repository in Unity (create a project using the same folder or clone then open in Unity Hub).
2. Import art assets into Assets/Art/ (Sprites, Tilesheets, Animated frames).
3. Create Tile Palette and RuleTile/RandomRuleTile/AnimatedRuleTile using 2D Tilemap Extras.
4. Create a scene following Assets/Scenes/README.md and attach Player prefab + scripts.
