Auto-generated Tile assets are placed under Assets/Tiles/AutoGenerated by the Generator.

How to use

1. In Unity, open the project in your preferred editor version (2022.3.55f1c1 recommended).
2. Ensure SugerWorld art is extracted to Assets/Art/SugerWorld (Tools -> Sunny Land -> Extract Art Zip in case you used the provided helper).
3. Run the generator: Tools -> Sunny Land -> Generate Auto Tiles. This will create Tile (.asset) files under:
   - Assets/Tiles/AutoGenerated/<group>/*.asset
   and a mapping.json at Assets/Tiles/AutoGenerated/mapping.json which records sprite -> group mapping.
4. Open Tile Palette and add tiles from Assets/Tiles/AutoGenerated/* to paint your Tilemap.

Convert to RuleTile (after you install 2D Tilemap Extras)

1. Install 2D Tilemap Extras (RuleTile, AnimatedRuleTile, RandomRuleTile) via Package Manager or import the 2d-extras package.
2. Restart Unity if necessary.
3. Run: Tools -> Sunny Land -> Convert Auto Tiles -> RuleTiles (the script will detect RuleTile in assemblies and create RuleTile assets under Assets/Tiles/RuleTiles/ based on the mapping.json).

Notes
- The initial generated tiles are plain UnityEngine.Tilemaps.Tile assets and require no external packages.
- The converter script will only run if RuleTile type is found (safely exits otherwise), so it won't break compilation if 2d-extras isn't installed.
