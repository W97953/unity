This folder contains notes on how to create RuleTile / RandomRuleTile / AnimatedRuleTile in the Unity Editor using the 2D Tilemap Extras package.

Steps (short):
1. Install 2D Tilemap Extras (from Unity-Technologies/2d-extras) via Package Manager or add it to the project.
2. Create a Tile Palette (Window -> 2D -> Tile Palette).
3. Right-click in Assets -> Create -> 2D -> Tiles -> Rule Tile (or Random Tile / Animated Rule Tile) to add tile assets.
4. For RandomTile: add multiple sprite variants in the inspector.
5. For AnimatedRuleTile: set animation frames and FPS in the inspector.
6. Paint the tile assets onto a Tilemap in a Grid GameObject.

See the course videos for detailed walk-throughs.
